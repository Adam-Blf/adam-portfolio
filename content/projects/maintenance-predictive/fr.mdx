## Le problème

Arrêter une machine trop tard coûte cher, l'arrêter trop tôt aussi. Le projet cherche à prédire une panne à 24 heures à partir de 15 variables mesurées.

## Ce que j'ai construit

Quatre modèles comparés : régression logistique, forêt aléatoire, XGBoost et perceptron multicouche. L'interprétabilité passe par SHAP. Le meilleur modèle est servi par une API FastAPI et un tableau de bord Streamlit.
